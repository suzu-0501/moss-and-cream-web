# MOSS AND CREAM Web 実装要件

## 1. 目的

店舗の雰囲気とメニューを最初に伝え、対象メニューを選ぶと、ドリンクが完成するまでの工程をスクロール操作で体験できるWebサイトを提供する。

## 2. 想定ユーザー

- スマートフォンから店舗やメニューを確認する来店候補者
- SNSや営業資料からサイトを訪問するユーザー
- ドリンクの特徴や価格を短時間で確認したいユーザー

## 3. 情報設計

### 店舗トップ `/`

1. 店舗外観を使ったファーストビュー
2. ブランドコンセプト
3. おすすめドリンク
4. 全メニュー
5. 店舗案内

おすすめドリンクおよび対象メニューの行から、ドリンク詳細ページへ遷移できること。

### ドリンク詳細 `/menu/pistachio-tiramisu-latte`

1. ドリンク名と概要
2. スクロール連動の制作工程
3. 現在工程と進捗率
4. 完成後のカスタマイズUI
5. 素材ストーリー
6. 注文イメージ

## 4. スクロールアニメーション要件

- ページのスクロール量を動画の再生位置へ連続的に割り当てる。
- クリックによる通常再生を主操作にしない。
- 下方向のスクロールで工程が進み、上方向で巻き戻る。
- 動画はループさせない。
- スクロール停止中は対応するフレームで停止する。
- 完成地点では完成フレームを保持する。
- 動画ロード完了までは完成ドリンク画像を表示する。
- モバイルとPCで適切な動画ファイルを選択する。
- 工程は `ICE + MILK`、`ESPRESSO`、`PISTACHIO`、`CREAM`、`FINISH` の順に表示する。

## 5. 完成後UI要件

- 完成地点で商品を左へ寄せ、右側からカスタマイズパネルを表示する。
- Regular / Largeのサイズを選択できる。
- Whole Milk / Oat Milkを選択できる。
- 選択内容に応じて合計金額を更新する。
- バッグ追加操作後は追加済み状態を視覚的に示す。
- 本サイトはサンプルのため、実決済は行わない。

## 6. レスポンシブ要件

- スマートフォン縦画面を最優先とする。
- タブレット、ノートPC、デスクトップへ段階的に最適化する。
- 動画、見出し、操作UIが重ならないこと。
- 主要なタップ対象は十分なサイズを確保する。
- 横方向の意図しないスクロールを発生させない。

## 7. アクセシビリティ要件

- 主要画像に代替テキストを設定する。
- ナビゲーションとボタンに識別可能なラベルを設定する。
- キーボード操作でリンク・ボタンへ到達できること。
- `prefers-reduced-motion: reduce` では動画スクラブを省略し、完成状態と情報を提示する。
- 色だけに依存せず、文字やアイコンでも状態を表現する。

## 8. パフォーマンス要件

- ファーストビューの主要画像を優先読込する。
- 動画読込中もレイアウトを安定させる。
- 画面幅に応じて動画素材を切り替える。
- スクロールイベントは `requestAnimationFrame` で描画更新を制御する。
- 不要になったObject URLやイベントリスナーを解放する。

## 9. 受入条件

- トップページの対象メニューから詳細ページへ遷移できる。
- 詳細ページでスクロール量に比例して動画フレームが変化する。
- 逆スクロール時に動画も逆方向へ戻る。
- 最終工程後にカスタマイズパネルが表示される。
- モバイル、タブレット、PCで主要コンテンツが閲覧・操作できる。
- 動画未読込時または低モーション設定時にも内容を理解できる。
- `npm run lint` と `npm run build` が成功する。

## 10. 店舗CTA・予約デモ要件

- ページを一定量スクロールすると、電話・アクセス・席予約の固定CTAを表示する。
- 電話CTAには架空番号 `0172-00-0000` を使用し、デモ番号であることを明示する。
- アクセスCTAは店舗情報セクションへ移動する。
- 席予約CTAから日付・時間・人数・席種を選択できる予約パネルを表示する。
- 予約完了演出を表示するが、入力内容の保存・外部送信・実予約は行わない。
- モバイルでは画面下部に収まる大きさへCTAを最適化する。
- `prefers-reduced-motion: reduce` ではCTAと予約パネルの演出時間を最小化する。
